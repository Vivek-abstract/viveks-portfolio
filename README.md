# Vivek Gawande — Portfolio

Personal portfolio website built with **Next.js 15** (App Router), **Contentful CMS** for blog content, and deployed on **Netlify** as a static site.

Live at [vivekgawande.in](https://vivekgawande.in)

## Tech Stack

- **Framework:** Next.js 15 (App Router, static export)
- **Styling:** CSS Modules, Bootstrap 5.3
- **Icons:** FontAwesome
- **CMS:** Contentful (blog posts)
- **Analytics:** Google Analytics (GA4)
- **Hosting:** Netlify
